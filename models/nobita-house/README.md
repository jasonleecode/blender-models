# 大雄家 · 经典动画版住宅模型

用本机 Blender 5.1 创建的可编辑住宅模型。采用旧版动画常见的红屋顶、浅黄外墙和蓝窗帘，室内布局参考 **2004 年及以前版本的推测户型**，保留二楼两间和室。

这是参考还原作品，**不是官方精确建筑图**。动画镜头、年代和版本之间存在差异；本模型的尺寸、层高、家具比例、院落和部分门窗位置为建模假设。

## 户型内容

一楼包含玄关、会客室、起居和室、父母卧室、厨房餐厅、浴室、洗面区和卫生间。二楼包含大雄的房间、哆啦A梦睡觉的壁橱、另一间和室、楼梯和前侧过道。

一楼地面标高 0.55 m，二楼 3.45 m，主屋屋脊约 7.5 m。这些数值是视觉还原时采用的假设，不代表动画官方尺寸。模型正面朝负 Y，东侧入口位于正 X；比例单位为米。楼梯从一楼北侧过道起步，向南上行，抵达二楼前侧平台；上下层开口一致。

房间内有独立制作的榻榻米、矮桌、坐垫、日式寝具、餐桌椅、厨房设备和卫浴。大雄书桌包含抽屉、作业纸、台灯、书本；寝床壁橱半开，露出蓝色被褥。未加入角色人物。

## 重建

所有几何和材质由 [create_nobita_house.py](create_nobita_house.py) 生成，不需要购买模型资产。源脚本会覆盖同名生成文件；手工修改前请另存一份。

```bash
cd models/nobita-house
blender -b -t 12 --python create_nobita_house.py
```

渲染采用 Cycles、32 采样和降噪；`model_info.json` 记录模型结构，`verification.json` 记录本机 Blender 5.1 的检查结果。
