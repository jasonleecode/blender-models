# 林间三角屋 · PINE / 02

使用 Blender 5.1 制作的两层 A 字形林间小屋，采用米制单位。

- `林间三角屋.blend`：完整、可编辑模型，双击或在 Blender 中打开。
- `林间三角屋_全景.png`：林地与建筑全景。
- `林间三角屋_建筑特写.png`：立面、阳台与屋顶天窗。
- `林间三角屋_两层剖视.png`：移除屋顶、玻璃和树林后的室内展示。
- `create_cabin.py`：生成模型及三张渲染图的脚本。

一层包括客厅、沙发、茶几、厨房和壁炉；二层包括卧室、床头柜、收纳柜和阳台。17 级楼梯连接两层。屋外有木质露台、座椅、花盆、石板步道、庭院灯和松林。

一层完成面约 1.10 米，二层完成面约 4.30 米，屋脊约 8.53 米。模型是建筑概念展示，不是施工设计。

右侧大纲视图按结构、屋顶、玻璃、露台、一层、二层、楼梯、树林及灯光分组。隐藏 `03 • Standing seam roof` 和 `04 • Glazing & frames` 可以查看室内。场景内设有全景、建筑特写和剖视三个相机。

所有材质均在文件内生成，无需外部贴图。在 Blender 中按小键盘 `0` 查看当前相机，鼠标中键旋转视角，滚轮缩放；按 `Z` 后选“材质预览”查看材质，按 `F12` 渲染。

在仓库根目录执行以下命令重新生成（需要 `blender` 在 PATH 中，也可以替换为 Blender 可执行文件的完整路径；会覆盖本目录中的模型和渲染图）：

```bash
blender -b -t 16 --python-exit-code 1 --python models/forest-cabin/create_cabin.py
```
